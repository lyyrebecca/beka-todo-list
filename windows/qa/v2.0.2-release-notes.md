# v2.0.2 Windows 修复候选版（未完成正式发布验收）

## 本次修复
- 修复悬浮球拖动、贴边、展开和位置恢复的坐标链：使用物理屏幕像素，显式转换 DPI，窗口布局与视觉动画分离。
- 修复圆球从右侧展开时主面板移出工作区；拖动结束、启动、分辨率或显示器变化时校正位置。
- 分别保存圆球和主面板的相对显示器位置；旧版屏外坐标不再导致窗口永久丢失。
- 增加托盘「找回窗口」；圆球保持可点击，不继承桌面展示的鼠标穿透。
- 位置保存防抖，设置写入失败不会关闭应用。
- 修复长期期间提醒只覆盖最初 60 天的问题；采用滚动提醒窗口及短周期 UI 线程调度，避免长定时器限制和取消/触发竞争。睡眠恢复时每项只投递最近一条到期提醒，不补发全部积压提醒。
- 二次启动的 `--import <file>` 转发实际文件路径，支持空格与中文。
- 损坏的结构化数据自动隔离；拒绝未知版本、缺失记录和不可识别的备份格式，不先清空本机待办。连续导入的安全备份使用独立文件名。

## 已有证据与发布限制
- Windows Server 2025 runner 上，旧版 v2.0.1 的真实鼠标流程复现主面板屏外位置；候选修复完成 100 次收起/展开、200 次实际鼠标拖动，无越界或进程退出。
- 本地 72 个自动化测试通过；最终包的 Windows UI、安装和便携验收以候选工作流结果为准。
- 100%/125%/150%/200% 缩放及负坐标副屏有几何算法测试，不能替代混合 DPI 实际显示环境。
- Windows 10/11、微软拼音及微信输入法组合输入、通知中心实际弹窗尚未验收。现有 UTM 虚拟机只有空虚拟磁盘，未安装 Windows。
- **候选版保持 Draft；不覆盖 v2.0.1 Latest，也不更新 Packages latest。** 未完成项见 [验收清单](v2.0.2-acceptance.json)。

## 候选文件与使用方式
| 系统 | 文件 | 使用 |
|---|---|---|
| Windows 10 22H2 / Windows 11 x64（目标支持，客户端验收待完成） | `LiquidTodo-Windows-x64-Setup-v2.0.2.exe` | 安装版；正常升级保留本地待办。 |

窗口不在屏幕内时，右键托盘图标选择「找回窗口」。安装包仍未使用 Authenticode 签名；仅通过项目 Release 下载，用 `SHA256SUMS.txt` 校验。
