# 层级备份兼容规则（开发中，尚未发布）

- 纯平面清单继续导出 schemaVersion: 1。
- 任何活动或归档条目具有 parentId 时导出 schemaVersion: 2。
- 新客户端兼容导入 v1 和 v2；旧客户端会拒绝 v2，不能让旧客户端忽略字段后把层级静默抹掉。
- parentId 为可选 UUID，根节点为 null/缺省；条目仍使用平面数组保存，渲染时按父子关系排列。活动与归档联合检查关系。
- 同级排序携带整个子树；改挂节点不能指向自己或后代。孤儿与循环输入恢复成可见根节点，而非丢弃内容。
- 完成父项包含活动后代；四秒撤销恢复整个完成分组。父项归档/恢复保留层级；进度计入已归档子项。
- Windows v2 实现与跨平台 fixture 验证未完成前，不发布这个层级版本。
