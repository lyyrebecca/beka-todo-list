# 层级备份兼容规则（macOS v2.1.0）

- 纯平面清单继续导出 `schemaVersion: 1`，兼容已发布 Windows v2.0.1。
- 任何活动或归档条目具有 `parentId` 时导出 `schemaVersion: 2`。
- Mac v2.1.0 可导入 v1/v2；旧版 Mac、已发布 Windows v2.0.1 不支持 v2，会拒绝导入。请勿把层级备份当作旧 Windows 可用文件，也不要手工删改版本号。
- Windows 层级版本在独立开发分支中，尚未发布。用户已暂停 Windows 客户端图形验收；本次发布不包含其修复或功能。
- `parentId` 是可选 UUID；根节点为 null/缺省，条目仍以平面数组保存。活动与归档联合检查关系。
- 同级拖动携带整个子树；不能将节点移到自己或后代之下。孤儿和循环输入恢复为可见根节点，不丢内容。
- 完成父项包含活动后代；四秒撤销恢复整个完成分组。父项归档/恢复保留层级，进度计入已归档子项。
- 导入先完整验证；含无效时间戳的备份整体拒绝，不会静默跳过后执行替换。导入前安全备份使用 UUID，避免连续导入互相覆盖。
